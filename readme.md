# uAirwaves

A single binary app TUI for uConsole with a HackerGadgets Antenna board (GPS/SDR/LoRA/RTC) specifically for enjoying
activities on the aviation airwaves.

- ADSB (`readsb`) JSON
- ACARS
- GPS + plotting

Target: 

```shell
Linux uconsole 5.10.17-v8+ #5 SMP PREEMPT Thu Jun 29 13:36:01 CST 2023 aarch64 GNU/Linux
```
